# Капсула в поездку

Капсульный гардероб на поездку из своих вещей. Указываешь место и даты (или температуры вручную) и размер багажа, и страница собирает небольшую капсулу: вещи сочетаются друг с другом по цвету и закрывают погоду каждого дня. Работает как сайт и как приложение на телефоне (PWA), без сети открывается последняя собранная капсула.

Страница: <https://iheartbeard.github.io/wardrobe-trip/>

## Как это работает

- Погода: если поездка в ближайшие 16 дней, берётся прогноз Open-Meteo (ощущаемая температура днём), иначе погода тех же дат прошлого года как ориентир. Можно задать вручную.
- Багаж: «Рюкзак» (~24 л) или «Маленький чемодан» (рюкзак плюс чемодан для ручной клади ~38 л) задают лимиты по курткам, слоям, футболкам, низу, обуви и головным уборам.
- Капсула: сначала закрывается каждый день поездки, потом добавляются вещи, которые дают больше новых сочетаний. Вещь можно закрепить или убрать, капсула пересоберётся.
- План по дням и чек-лист сборов, отметки сохраняются на телефоне.

## Данные

Вещи, правила слоёв и проверка цвета взяты из [wardrobe-fits](https://github.com/iheartbeard/wardrobe-fits) (`js/model.js`, `js/lib/`, `js/data/`). Это копия: если вещи меняются там, их нужно перенести и сюда. Летние вещи для поездок лежат в `js/trip/summer.js`.

```
index.html            разметка страницы
css/styles.css        общие стили гардероба
css/trip.css          стили капсулы
js/trip/app.js        интерфейс
js/trip/capsule.js    подбор капсулы и плана по дням (без DOM)
js/trip/forecast.js   место и погода на даты поездки
js/trip/summer.js     летние вещи для поездок
js/model.js, js/lib/, js/data/   модель гардероба из wardrobe-fits
sw.js                 service worker (офлайн)
```
