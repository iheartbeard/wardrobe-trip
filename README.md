# Капсула в поездку

Капсульный гардероб на поездку из своих вещей. Указываешь место и даты (или температуры вручную) и размер багажа, и страница собирает небольшую капсулу: вещи сочетаются друг с другом по цвету и закрывают погоду каждого дня. Работает как сайт и как приложение на телефоне (PWA), без сети открывается последняя собранная капсула.

Страница: <https://iheartbeard.github.io/wardrobe-trip/>

## Как это работает

- Погода: если поездка в ближайшие 16 дней, берётся прогноз Open-Meteo (ощущаемая температура днём), иначе погода тех же дат прошлого года как ориентир. Можно задать вручную.
- Багаж: «Рюкзак» (~24 л) или «Маленький чемодан» (рюкзак плюс чемодан для ручной клади ~38 л) задают лимиты по курткам, слоям, футболкам, низу, обуви и головным уборам.
- Капсула: сначала закрывается каждый день поездки, потом добавляются вещи, которые дают больше новых сочетаний. Вещь можно закрепить или убрать, капсула пересоберётся.
- План по дням и чек-лист сборов, отметки сохраняются на телефоне.

## Данные и правила

Своих копий гардероба у капсулы нет. Модель сезонов, вещи, слои, температуры, готовые образы и проверка цвета берутся из [wardrobe-fits](https://github.com/iheartbeard/wardrobe-fits) прямо с сайта: оба проекта на одном домене, и `js/trip/wardrobe.js` импортирует модули из `/wardrobe-fits/js/`. Поэтому правка гардероба там сразу работает и здесь. Сезон, которого нет в основном проекте (сейчас весна и лето), капсула не собирает.

Своё у капсулы:

- `js/trip/rules.js` — правила сборов: лимиты багажа, обувь, неудобная для ходьбы, обувь под мероприятие, джинсы (в последнюю очередь, максимум 2), средний слой максимум 2 и худи из них не больше 1;
- `js/trip/capsule.js` — подбор: сначала обувь, которая закрывает погоду поездки, потом остальные вещи так, чтобы всё сочеталось со всем: каждая пара вещей, которые носятся вместе, и каждый образ, который можно собрать из капсулы под погоду поездки, проходит проверку цвета основного проекта;
- `js/trip/forecast.js` — место и погода на даты поездки, `js/trip/app.js` — интерфейс.

## Разработка

Рядом с этим репозиторием должен лежать клон wardrobe-fits (`../wardrobe-fits`), тогда пути совпадают с сайтом.

```sh
cd ..            # папка, где лежат оба репозитория
python3 -m http.server 8080   # http://localhost:8080/wardrobe-trip/
cd wardrobe-trip && npm test
```
